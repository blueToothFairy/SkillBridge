# SkillBridge Frontend

UI Next.js cho SkillBridge MVP.

## Chạy local

```bash
npm install
```

```bash
# macOS / Linux / Git Bash
cp .env.local.example .env.local

# Windows PowerShell
Copy-Item .env.local.example .env.local
```

```bash
npm run dev
```

Mở `http://localhost:3000`. Backend mặc định: `http://localhost:5000`.

Hướng dẫn đầy đủ (cả hệ thống): xem [`../README.md`](../README.md).
